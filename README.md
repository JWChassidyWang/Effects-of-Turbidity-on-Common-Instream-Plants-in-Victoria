# Effects-of-Turbidity-on-Common-Instream-Plants-in-Victoria
Jing-Wen Wang, Laila Conti, Scott McKendrick, Christopher S. Jones, Joe Greet

## Overview
This repository contains the data and R scripts used to test the responses of two common instream species in Victoria, Vallisneria australis and Cycnogeton procerum, to four levels of turbidity (control, low, medium, and high) common in Victorian rivers.
